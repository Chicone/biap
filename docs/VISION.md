# BIAP Vision

## Biomedical Image Analysis Platform

BIAP is an open-source AI platform for quantitative biomedical image analysis.

The platform is designed to support the complete workflow from raw microscopy images through quantitative feature extraction, exploratory analysis, machine learning and, ultimately, AI-assisted scientific discovery.

---

## Current capabilities

- Biomedical dataset management
- Image segmentation
- Morphology analysis
- Intensity analysis
- Texture analysis
- Feature Analysis
- PCA
- UMAP
- Interactive Projection Viewer

---

## Near-term objectives

- Complete BBBC021 importer
- Multi-channel microscopy datasets
- Classical machine learning
- Explainable AI

---

## Long-term objectives

- Deep Learning
- Graph Neural Networks
- Large Language Models
- Agentic AI
